# Jomark Aldave: portfolio

Personal portfolio site: senior software engineer, AI-augmented full-stack engineering.

Built with Next.js (App Router), React, TypeScript and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Edit the content

All text lives in `src/content/portfolio.ts`: profile, experience, AI work, projects, skills and contact links. The page layout is in `src/app/page.tsx`.
